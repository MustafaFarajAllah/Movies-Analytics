# Movies Analytics: Large-Scale Data Engineering, Visualization, and Machine Learning
Developed an end-to-end movies analytics project involving approximately 1.5 million records across six datasets. Engineered and integrated large-scale data from multiple sources to create analysis-ready datasets, uncover industry trends, and support data-driven insights. Built analytical visualizations and dashboards using Plotly, Matplotlib, Seaborn, Power BI, and Excel, while applying machine learning techniques to identify patterns and generate predictive insights.

## Key Contributions
- Processed, cleaned, and integrated approximately 1.5 million records from six datasets.
- Designed data-engineering workflows to transform raw data into reliable, analysis-ready datasets.
- Conducted exploratory analysis to identify trends, relationships, and patterns in movie data.
- Created interactive dashboards and visualizations using Plotly, Power BI, and Excel.
- Produced statistical visualizations using Matplotlib and Seaborn.
- Applied machine learning techniques to support predictive and pattern-based analysis.
